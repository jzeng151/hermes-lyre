## Task Rules

- Keep each task reviewable on its own: one rule per pull request.
- Do not implement behavior outside the spec. A new rule or change needs a spec update in the same pull request.
- Attach evidence in [test-evidence.md](test-evidence%20%28%233-%239%2C%20%2313-%2315%29.md) before marking a task done.
- Formatter code never imports Hermes and never does I/O.
- File paths follow the layout in the design doc: plugin code and tests live under `lyre/`.
- Test commands run from `lyre/`; `pytest` below is short for `uv run --no-project --with pytest --with pyyaml pytest`.
